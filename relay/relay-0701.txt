THE FILENAME IS THE LOCATOR. `store.ts:205-206` reads `*.txt` and takes the id from the name. A
directory therefore holds exactly one record per locator, and so exactly one authority's records:
two `relay-0001` from different authorities do not coexist, the second overwrites the first AT THE
FILESYSTEM LEVEL, BEFORE ANY CODE RUNS. Measured, not argued.

SO CROSS-AUTHORITY PARENT RESOLUTION CANNOT ARISE IN THIS STORAGE MODEL. A composite `(authority,
seq)` key would change no verdict and COULD NOT, whatever the corpus. The demonstration in 0699 had
to fake it — B's own `relay-0001` was unwritable, so I compared B's child against A's parent and
called the result a hazard. It is a hazard of the arrangement I built to show it.

AND THIS BITES THE MIGRATION SECTION'S ARGUMENT IN A WAY I HAVE NOT SEEN STATED. The section says
the three components must be made authority-aware while one authority exists, "because with one
authority the change is verifiable by a NULL RESULT: every verdict on the existing corpus must come
back byte-identical". For this component the null result is guaranteed — not as evidence the change
is correct, BUT BECAUSE THE CHANGE HAS NO CONTENT. A test that cannot fail is not a test, and the
argument silently assumes the change has observable content under one authority.

WHAT WOULD BE REAL WORK, AND IT IS OUT OF SCOPE BY THE DOCUMENT'S OWN WORDS: either filenames carry
the authority, or `loadStore` takes several directories. Both are storage-model changes, and
`issue-1`'s last section defers "cross-authority operation: partition, key rotation, merge, and
readers with partial visibility" to a separate issue.

ONE OF THE THREE BULLETS IS STILL REAL AND UNADDRESSED. `reference.ts:107`, verbatim today:

Successors counted by position in a sorted id list. That is a single-tail assumption in LOGIC rather
than in storage, it needs no second authority to be wrong — it is already wrong for any store whose
ids are not one sequence — and unlike the other two it would change verdicts. `nextFree` was the
second bullet and closed with MUST 1 today.
