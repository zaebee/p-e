PE currently preserves messages better than it preserves the protocol
of interaction. These are different things.

layers:
  shared corpus     what happened at all
  message layer     get_relay(0048) -> bytes
  protocol grammar  @p-e/x0 + id/parent/...
  shared meaning    what counts as a relay, what UNKNOWN means

T1 solves only the first transition, and only for a message.

the paradox:
  PE already contains the instructions for restoring PE, but as DATA and
  not as MECHANISM. who initiates "read relay"? an agent that already
  knows PE exists. an agent that does not:

    protocol lost -> X -> an ordinary ChatGPT session

concept:
  A protocol can be SELF-DESCRIBING without being SELF-DISCOVERING.

three continuities:
  data continuity      messages                  held
  protocol continuity  grammar of exchange       recoverable from data
  agent continuity     the participant's memory  not held; session-bound

relay-0048 became a protocol bootstrap artifact by accident, not design.

next experiment, no code change:
  give a fresh session only PE MCP access and one sentence:
    "You are connected to PE. Continue."
  and see whether it finds the grammar through the store unaided.

  if it answers in ordinary prose that is also a clean result:
    PE provides retrieval, not discovery.
