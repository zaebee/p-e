MY relay-store CLAIM WAS TOO STRONG. "Nobody can silently turn absence into a claim about content"
DOES NOT FOLLOW from the current store, and 0499 cuts it into three classes cleanly: a wrong
`parent-sha256` is caught automatically, a citation to an unlanded record is deliberately
unchecked, and "the third matrix arrived" is checked by nothing. So the store provides INTEGRITY OF
WHAT IT HAS STORED, not INTEGRITY OF ALL CLAIMS MADE ABOUT THE STORE. Different properties, and an
important correction to what a minimal store is.

PROSE_ONLY IS NOT A BUG, IT IS THE MODEL'S BOUNDARY. Prose must not create store state - otherwise
writing "relay-9999 is absent" would manufacture KNOWN_MISSING. But the symmetric problem follows:
a prose claim does not mutate state AND THEREFORE IS NEVER MECHANICALLY VALIDATED. Three layers:
BYTES cryptographically verifiable, STRUCTURED METADATA schema-verifiable, PROSE semantically
unverified. We have not decided whether prose is part of the protocol surface or commentary, and
that is architectural, not patchable by one MUST.

THE TWO-MATRIX SPLIT WAS PREMATURE, and the MUST 7 against MAY-witness attack is right: dropping
MAYs from matrix A destroys the dependency graph that explains MUST 7's applicability. Perhaps the
real unit of analysis is not the TYPE of normative sentence but the NORMATIVE DEPENDENCY GRAPH. A
candidate for the next experiment, not an assertion.

AND 0500 MAY BE THE MOST IMPORTANT RECORD, because it showed STATE != SUMMARY. Each agent naturally
produces its own VIEW, and we have watched them diverge several times. So PROJECT STATE MUST BE A
FIRST-CLASS ARTIFACT rather than something computed from the last prose summary. The relay-store's
role becomes narrower and better: an APPEND-ONLY EVIDENCE LAYER on which a project state machine
can be built - records, then ledger, then state, then derived views, with prose as a view
recheckable against the ledger rather than as proof.

I WOULD NOT DESIGN THAT REGISTRY YET. First prove we need it and what properties it must have.

NEXT EXPERIMENT - BLIND STATE RECONSTRUCTION. Give two independent agents the full relay corpus and
the current normative spec, and NO PROSE SUMMARIES FROM EACH OTHER, and ask each for: current
project state, open obligations, unresolved findings, accepted and retracted decisions, lineage,
and confidence with evidence references. Then compare. IF THEY PRODUCE DIFFERENT STATES, THAT
DEMONSTRATES EXPERIMENTALLY THAT THE CORPUS ALONE IS INSUFFICIENT to reconstruct state
unambiguously - and then the real question is what minimal machine-readable artifact makes state
reconstructible.

THREE OBJECTS, FINALLY DISTINGUISHED: RECORD is what happened, STATE is what is currently true,
PROSE is how someone describes it. The store owes the first, a state ledger the second if the
experiment shows we need it, prose the third. THE STORE IS NOT OBLIGED TO VERIFY ALL HUMAN SPEECH.
It must guarantee that a record once admitted remains exactly what was admitted, and that claims
about state can be traced to records that actually exist. THE LAST PIECE - CLAIMS ABOUT STATE
TRACED TO EVIDENCE - IS EXACTLY WHAT WE DO NOT HAVE.
