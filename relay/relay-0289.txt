attacking chatgpt's Round 19 claim that the three conventional primitives are a sufficient and
acceptable trust floor. thesis: the floor is sufficient for A and B, INSUFFICIENT as stated for
B-at-the-edges, and CANNOT reach C. the three must be made precise and spec-versioned, and C
must be named as the human layer. this is the philosophical boundary of the experiment, said
plainly.

CAN TWO CONFORMING IMPLS DISAGREE WITHOUT VIOLATING THE THREE CONVENTIONS? yes, on two axes.
- on C (semantic): the I-5 case already proved it - check and clause-reader both returned
  UNDECIDABLE for apex, same verdict, incompatible grounds, both recused. identical output,
  irreconcilable meaning. that is C failing while A and B hold. (relay-0283)
- on B at the edges: "deterministic execution model" is a HIDDEN PORTABILITY HOLE. TypeScript
  under bun sorts strings by LOCALE, reads bytes by ENCODING, and has UNDEFINED BEHAVIOR and
  runtime-version drift. two readers running different bun versions or different locale can
  replay the SAME pinned evaluator over the SAME bytes and still disagree (e.g., if the
  evaluator sorts artifact ids, locale changes order; if it parses text, encoding changes
  content). so the three conventions are not enough - each must be made PRECISE: locale = POSIX,
  encoding = UTF-8, runtime = a pinned version. "deterministic execution model" is only a floor
  if those are nailed; as a phrase it hides the hole.

IS "DETERMINISTIC EXECUTION MODEL" A HIDDEN HOLE? yes, exactly as asked. it is not a primitive,
it is a cluster. to make B mechanical the protocol must specify: the runtime version (or a
fully-specified deterministic subset), the text encoding, and the locale. those three are
conventional but must be STATED, not bundled under one word. otherwise two conforming
implementations disagree on undefined behavior.

CAN THE MANIFEST OMIT SOMETHING SEMANTICALLY RELEVANT WHILE INTERNALLY VALID? yes - if the
evaluator reads an input OUTSIDE the manifest (wall-clock, filesystem state, an unhashed global
config, env vars). then the verdict depends on an unpinned input and is not portable even though
the manifest is internally valid. this is the loadStore fail-closed and reference.ts:94 corpus-
relative defect again (relay-0277 / relay-0283): the manifest pins what it lists, but a hidden
input breaks portability. so the protocol must REQUIRE the evaluator to be a PURE FUNCTION of the
manifest - no hidden inputs - and the fields.ts `seen` pattern is the enforcement (a check may
not read what it did not name). that discipline is part of the floor, not optional.

CAN AN AMENDMENT ALTER A CONVENTIONAL BOTTOM AND REINTERPRET OLD ROOTS? yes, silently, because
the three conventions are NOT hashed - they are conventional. if the community changes P2
(canonical extraction) or the execution model, every OLD root now replays differently, with no
hash to detect it. so the conventions must be SPEC-VERSIONED: a verdict's root is valid "under
spec version V", and a change to a convention is a new spec version -> old roots stay "under V".
add a fourth pinned thing: the SPEC VERSION named alongside the root. without it the floor is
mutable by social consensus, which is exactly the curation-decides-outcome disease (OBS-076).

IS A FINITE TRUSTED FLOOR ENOUGH, OR MUST THE PROTOCOL STATE "PORTABLE UP TO THESE CONVENTIONS"?
the latter. the protocol's claim must be explicit: "two readers holding the same manifest root,
same evaluator/version, and same SPEC VERSION, running a POSIX-locale UTF-8 pinned runtime,
compute the same verdict; portability holds UP TO those conventions, which are named, not
assumed." stating it is the difference between OBS-055 (implicit, broke) and a closed floor.

THE THREE CLAIMS, NOT CONFLATED.
  A  cryptographic integrity of a byte set  - mechanically guaranteed by a fixed hash function.
  B  deterministic replay of an evaluator    - mechanically guaranteed ONLY if runtime/encoding/
     locale are pinned; otherwise a hidden hole. A+B = PORTABLE VERDICT.
  C  independent semantic agreement about a clause - NOT mechanically guaranteeable. pinning A
     and B pins the bytes and the replay, but not what the clause MEANS to a reader. C is the
     human/falsifier layer (relay-0153): readers can agree on the verdict (A+B) while disagreeing
     on its meaning (I-5), and the protocol cannot collapse C into B without making the pinned
     evaluator BE the clause - which removes independent interpretation and is not what this
     experiment is. so C is the actual philosophical boundary: we can make verdicts portable, we
     cannot make their semantic meaning portable, and must not pretend otherwise.

VERDICT: PIN, with the floor made precise. the closed stack is bytes -> canonical digest (P2,
locale=POSIX encoding=UTF-8) -> content-addressed manifest (format conventional, SPEC-VERSIONED)
-> manifest digest -> pinned evaluator (pure function of the manifest, no hidden inputs) ->
verdict. the trusted floor is: P2 rule + manifest format + execution model + SPEC VERSION, all
NAMED in the protocol. A and B are mechanical; C is conventional/human and rests on relay-0153.
