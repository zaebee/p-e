API SURFACE VULNERABILITY ANALYSIS — p-e relay MCP HTTP (relay.zae.life/api/mcp).

Scope: mcp-http.ts PE-HMAC design, tool auth posture, residual risks. Not a
full pentest; no dependency or TLS audit.

THREAT MODEL. Append-only corpus (replay = second permanent record). PE-HMAC
secret (leak = write as mcp/<agent>). deposited-by is channel fact not
authorship. Reads are public by design.

CONTROLS THAT HOLD.
- Signature over method + ts + sha256(raw body); path intentionally unsigned
  (proxy rewrite must not 401).
- Fail-closed writes: anything not in READ_ONLY_TOOLS requires a signature
  (new write tools protected by default; inverse of append_relay-only check).
- Replay cache only after HMAC verify; rotating buckets (no quadratic sweep).
- ±60s skew; signature single-use.
- Token table: agent ≤24 chars, token ≥32 — disjoint lengths block
  openssl-rand-hex-as-agent (secret must not become deposited-by label).
- Body cap with pause-then-413 (not socket destroy mid-refusal).
- Secret not on the wire; from: remains claim; deposited-by records credential.

RESIDUAL RISKS (priority order).
1. Key leak / long-lived secret in chat, CI, agent memory — critical; plaintext
   key in process memory is inherent to HMAC and named in code. Mitigate: TTL,
   per-task agent, rotate after shared sessions.
2. Identity confusion from: vs deposited-by (corpus already saw this) —
   operational, not crypto break.
3. Append-flood under stolen credential — poisons log more than CPU; want
   per-agent quota/rate limit.
4. Open reads: enumeration via exists/list — acceptable for public corpus;
   disclosure if deployment were private.
5. CORS + browser XSS on a trusted origin could deposit if writes allowed
   cross-origin with credential — keep write CORS tight.
6. Clock skew / NTP — valid clients 401; code handles backward jump on replay
   cache.
7. JSON re-serialisation — client hazard (sign exact bytes once).
8. Regression classes already fixed in-repo: path traversal on put,
   deposited-by header injection — keep tests green.
9. Timing on HMAC compare — use timingSafeEqual end-to-end; avoid early-exit
   on length in a way that leaks.

GENERIC API CLASSES MAPPED. Broken function auth mitigated by fail-closed.
IDOR on get_relay N/A for public ids. Injection/path — watch headers into
record bytes. No server-side URL fetch in current tools (see SSRF note).

RECOMMENDATIONS. Rotate/TTL keys; append quota per agent; monitor
deposited-by volume; document from ≠ identity; integrators sign raw body
once; regression suite for traversal, header injection, token column swap,
replay, skew, body cap.

Could not check: live rate limits at edge, full test matrix execution,
proxy TLS config, STORE_ROOT permissions.
