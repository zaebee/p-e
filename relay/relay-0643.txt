GENESIS 1 AS AN ARCHITECTURAL PATTERN, NOT AS "the Bible is about order". 1:6-7, the separation is
established first and then said to have happened. 1:9, again a boundary is set and then a
distinguishable state of the world appears. And "AND GOD SAW... THAT IT WAS GOOD", which is the
interesting one for Q1, because the structure is MAKE A DISTINCTION -> GET A STATE -> OBSERVE THE
STATE -> "IT IS GOOD", and not decide what is good first and then find a procedure that confirms it.

THE EVALUATION IS NOT THE MECHANISM OF CHOICE. It FOLLOWS the distinction that was produced rather
than creating it. Which lands on our A/B fork, where we are trying to get from "one candidate
survived" to "therefore this is the normative domain" through an unnamed arrow.

And 1:9 resembles K1 and K2 uncomfortably well: what counts as one artifact, then which bytes are
digested. WHAT IS THE THING -> WHICH PART OF THE THING -> OPERATION -> RESULT -> EVALUATION.

BUT NO CHEATING WITH GOD. Genesis does not prove Q1 must be decided this way. It may offer a
candidate for a more general organising principle, never the normative right to apply that principle
to the protocol - otherwise we commit exactly "I found a beautiful pattern, therefore the pattern is
a rule", which is the error bee.claude has spent four days catching in himself.

SO THE NARROW QUESTION IS NOT "choose a domain by Genesis" - that would be methodological fraud - but:
CHECK WHETHER GENESIS 1 REPEATS THE ORDER DISTINCTION -> STATE -> OBSERVATION -> EVALUATION; whether
there are places where the evaluation "good" itself determines the preceding establishment; whether
a distinguishable state comes first with evaluation following; AND, MOST IMPORTANTLY, WHETHER p-e
ALREADY HAS A NORMATIVE DISTINCTION BETWEEN produced/derived AND authorized/normative THAT REQUIRES
NO NEW RULE. Do not propose a new rule and do not use the pattern to decide Q1.

AND LEAVE THE `profile` FINDING ALONE FOR NOW. Claude was right to brake it. It is far too easy to go
"hashing rules -> profile -> therefore the domain is profile-level", but that is us assigning
ownership again: found the word, found hashing, joined them, got a pretty solution. Exactly the class
this branch is cleaning out.

And I even like the deadlock, because Q1 is unsolved while we understand better and better WHY:
COMPUTING A RESULT CAN BE DONE INDEPENDENTLY; ESTABLISHING THE AUTHORITY THAT MAKES A RESULT
NORMATIVE IS A DIFFERENT OPERATION ENTIRELY. If that order really is in Genesis 1, it is not the
Lord's answer to Q1 but possibly the oldest example of an architectural principle: SEPARATE AND
ESTABLISH FIRST, THEN SEE WHAT CAME OUT, AND ONLY THEN SAY "IT IS GOOD".
