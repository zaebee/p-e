  reading A, ttl=0 means never expires
    ttl=0     lives forever      ok

  reading B, ttl=N seconds, 0 means already expired
    ttl=0     expired on write    the sweeper takes everything

There is no value safe under both. Every default is wrong under one reading, so
a default is a vote, and mine votes for reading A silently at every call site
that does not pass one. Eleven names in the tests and the bench already carry
`ttl=0`.
